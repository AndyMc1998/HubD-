How to make the zip
  1. On a Windows PC, install Diablo II (version 1.14d from your Blizzard account works without a CD).
  2. Open the install folder, select its contents, and zip them (right-click → Compress to ZIP file).
  3. To save memory, leave out the cutscene files d2video.mpq / d2xvideo.mpq. If the game won't start without them, put them back.
  4. Get the zip onto your iPhone (iCloud Drive, AirDrop to Files) and pick it above.
Controls on iPhone
  • Tap / hold: left click (move, attack, pick up).
  • R button: next touch is a right click. Double-tap R to lock it on.
  • ⌨ button: shows game keys (Esc, Alt, Tab, I, C, S, 1–4, Shift…).
  • Turn your phone sideways. For full screen, use Share → Add to Home Screen and open HubD from there.
